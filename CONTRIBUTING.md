# Como contribuir

Obrigado pelo interesse em melhorar o Anatomy Studies. Você pode contribuir com correções anatômicas, novas questões, melhorias na interface ou ajustes no visualizador 3D.

## Relatar um problema

Abra uma issue com o comportamento esperado, o que aconteceu e os passos para reproduzir. Para problemas gráficos, informe navegador e dispositivo; uma captura de tela ajuda. Em correções anatômicas, inclua a questão ou estrutura afetada e uma referência verificável.

## Preparar uma alteração

1. Faça um fork e crie uma branch para sua alteração.
2. Instale as dependências com `npm ci` e execute `npm run dev`.
3. Mantenha a alteração focada e siga as convenções dos arquivos existentes.
4. Execute `npm test` e `npm run build`.
5. Abra um pull request explicando o problema, a solução e como verificou o resultado. Para mudanças visuais, inclua capturas de tela.

## Conteúdo e modelos

Não invente nomes, relações anatômicas ou respostas. Ao adicionar questões, confira respostas aceitas, respostas incompletas e explicações. Use alvos 3D apenas quando a estrutura estiver verificada no modelo.

Antes de adicionar modelos, imagens ou outros materiais externos, documente sua fonte, autoria e condições de redistribuição. Não inclua dados pessoais, credenciais ou arquivos de pesquisa que não façam parte da aplicação.
