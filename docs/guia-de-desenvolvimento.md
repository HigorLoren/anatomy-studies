# Guia de desenvolvimento — Anatomia Humana

## Objetivo

Construir uma plataforma de aprendizagem de anatomia humana com exploração 3D, identificação de estruturas e prática ativa. O conteúdo deve apresentar cada atividade como estudo de anatomia, sem referências a contexto institucional, cronogramas ou avaliações.

## Fonte de conteúdo

Use [o catálogo de estruturas (unificado e resumido)](./catalogo-de-estruturas-anatomicas.md) como escopo inicial. Cada estrutura deve ter, quando disponível:

- nome anatômico;
- sistema, região e tipo de estrutura;
- modelo 3D ou imagem de referência;
- descrição curta e relações anatômicas;

Não inventar nomes, relações ou respostas anatômicas.

## Formatos de questões

### Identificação no modelo 3D

Exibir cinco opções numeradas no modelo 3D. A pessoa deve informar o número correspondente à estrutura perguntada.

Exemplo:

> Qual é o Lobo Frontal?

Este formato terá 10 questões.

### Denominação de estrutura

Exibir uma imagem de uma estrutura e solicitar seu nome.

Exemplo:

> Denomine a estrutura.

A imagem de exemplo representa o Músculo Diafragma.

Este formato terá 3 questões.

### Completar a frase

Exibir uma frase com uma lacuna. A pessoa deve preencher o termo anatômico correto.

Exemplos:

> O tendão do calcâneo é formado por tendões dos músculos Gastrocnêmio e _______________
>
> Resposta: Sóleo

> Os tendões dos músculos Gastrocnêmio e sóleo formam o ______________
>
> Resposta: Tendão do Calcâneo

Este formato terá sete questões.
